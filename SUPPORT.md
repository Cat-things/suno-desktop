# Getting help

| You want to…                                         | Go here                                                                                                                                                                                        |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ask how something works or get help setting it up    | [Discussions → Q&A](https://github.com/Cat-things/suno-desktop/discussions/categories/q-a)                                                                                                     |
| Suggest a feature or share an idea                   | [Discussions → Ideas](https://github.com/Cat-things/suno-desktop/discussions/categories/ideas)                                                                                                 |
| Pitch a plugin or theme for Suno++                   | [Plugin ideas](https://github.com/Cat-things/suno-desktop/discussions/categories/plugin-ideas) or [Theme ideas](https://github.com/Cat-things/suno-desktop/discussions/categories/theme-ideas) |
| Report something in the app that's broken            | [Open an issue](https://github.com/Cat-things/suno-desktop/issues/new/choose)                                                                                                                  |
| Report a security vulnerability                      | Privately, see [SECURITY.md](SECURITY.md). Please don't open a public issue.                                                                                                                   |
| Fix a problem with your Suno account, credits, songs | Suno's own support at [help.suno.com](https://help.suno.com). We can't access Suno accounts.                                                                                                   |

Before opening an issue, check the [FAQ and known issues](README.md#-faq) in the README; the answer might already be there.

Suno Desktop is unofficial and not affiliated with Suno, Inc., so Suno's support team can't help with the app itself.
